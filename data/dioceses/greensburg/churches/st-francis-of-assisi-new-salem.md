## Holds Mass

Yes. The 25 October 2026 bulletin (container 14/0702, page 1, rendered) lists "Masses in Footedale": Saturday 4:00 pm, Sunday 9:30 am, and Tuesday and Thursday 8:00 am. The diocesan directory (190FS) has the same weekend times (Saturday 4:00 p.m., Sunday 9:30 a.m.).

## Name and address

GCatholic 24177 ("St. Francis of Assisi", 528 Footedale Rd., New Salem, PA 15468) and the diocesan directory (190FS, "St. Francis of Assisi Parish, Footedale Site", 528 Footedale Road, New Salem) agree; Footedale is the village, New Salem the postal town. The bulletin names the site only as "Footedale". The record name adds "(Footedale)" to tell it from the Masontown church of the same parish. Coordinates from GCatholic's Plus Code 87F2W568+MM (39.9116875, -79.8333125); the directory has no map pin for this site, and a Nominatim search found no OSM object to compare.
