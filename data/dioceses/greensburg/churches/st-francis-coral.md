## Holds Mass

Yes. The 25 October 2026 Our Lady of the Assumption bulletin (page 1, Mass Times) lists Saturday 6:00 PM and Sunday 9:00 AM at Coral, and weekday Mass 8:00 AM at Coral, Tuesday to Friday. The directory site page 070CS has the same weekend line ("Saturday: 6:00 p.m.; Sunday: 9:00 a.m.").

## Name and address

Name: the parish homepage calls the building "St. Francis" ("St. Francis, 555 First Street, Coral, PA"), after St. Francis Parish, Coral (Graceton), which the Former Churches Directory lists as closed in 2008 into Our Lady of the Assumption. The bulletin says only "Coral"; GCatholic 24109 and the directory (070CS, "Our Lady of the Assumption Parish, Coral Site") use the parish's name. name_verified false: only the parish site gives the building's name.

Address: the directory site page 070CS and the parish homepage both give 555 First Street, Coral, PA 15731. GCatholic 24109 gives "250 1st St., Coral", and so do the stale directory base page (LocationID=070, "250 First Street, Coral") and the empty LPi org ("250 First St, Coral, PA, 15731-0250"); the mailing address's ZIP+4 is also -0250, so "250" looks like an old box-number address rather than a building. The record follows 555 First Street (the parish's own current page and the directory's site page). address_verified stays false because GCatholic disagrees.

Coordinates: the directory's map pin (40.5005917, -79.1728776); a Nominatim reverse lookup there returns 1st Street, Coral (an interpolated house number, "562"), consistent with 555 First Street. GCatholic's Plus Code 87G2GR3J+J9 (40.5040625, -79.1690625) is about 500 m north-east, on Neal Road, Graceton per Nominatim, near the parish office's 2434 Neal Road mailing address, so it was not used.
