## Publisher

Holy Spirit is one canonical parish formed by merging the four "Route 20" churches: St. Mary's
(Hamilton, the principal church), St. Bernard's (Waterville, parish offices), St. Joseph's
(Oriskany Falls) and St. Joan of Arc Mission (Morrisville). The Rome Sentinel reported the
decree; its weekdays date it to June/July 2020. I have **not** read a Holy Spirit bulletin, so
"one bulletin for all four" is inferred from the merger and from route20catholic.org (the four
churches' earlier shared site) now redirecting to holyspiritrcparish.org. It is the likely
shape, but it is inference, and this row should not be promoted until the bulletin is read.

## Worship sites

The four churches the merger names, each in GCatholic too. The decree "does not close any of the
churches, but it will allow for discussions to begin about which churches can be maintained
going forward", so whether all four still have weekend Mass in 2026 needs the current
bulletin. See each church's "Holds Mass".

## Website and bulletin provider

holyspiritrcparish.org is the parish's site, and the old route20catholic.org redirects to it.
It answers plain HTTP requests with a Cloudflare challenge (HTTP 403, `cf-mitigated:
challenge`), and a real browser could not be run where this was researched, so neither its
bulletin page nor its provider could be read. A ParishesOnline organization exists for
St. Mary's (`st-marys-church-13346`) but lists no issues at all, so the bulletin is not there.
Older self-hosted bulletins under route20catholic.org/wp-content/uploads/ (2025) now 404.
