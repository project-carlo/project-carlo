## Website and bulletin provider

`other`, recipe `page-pdfs https://sp4c.org/current-bulletin/ filename=Year*.pdf`. The Current Bulletin page links the current issue alongside non-bulletin PDFs (cemetery rules, a reimbursement form, an archdiocesan sponsor certificate); without the page and filter, `fetch:check` on 2026-11-13 read the /2026-bulletins/ page and picked the cemetery rules. With them it picked `Year-A-33rd-Sunday-in-Ordinary-Time-November-15-2026.pdf`. File names spell out the liturgical year and Sunday (`Year-A-...`; older 2026 names run the words together, `YearATheBaptismoftheLordJanuary11-2026.pdf`), so the filter is `Year*` rather than `Year-A-*`, which would stop matching when Year B begins at Advent.
