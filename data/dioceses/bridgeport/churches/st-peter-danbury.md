## Holds Mass

St. Peter's 1 November 2026 bulletin (page 1, read 2026-11-12) lists St. Peter Church, 104 Main Street, with Saturday Vigil 5:00pm; Sunday 7:30am, 9:00am (Spanish), 10:30am, 12:00 noon and 5:00pm (Spanish); and weekdays Monday-Saturday 7:30am and Monday-Friday 12:10pm.

The roster entry mass-times:1167-st-peter-church-aparecida-masses comes from the diocese's directory note that some Our Lady of Aparecida Masses are "At St. Peter Parish, Danbury". It is this building, so it is linked here. Neither St. Peter's bulletin nor Aparecida's own site (both read 2026-11-12) lists an Aparecida Mass here now; Aparecida's site gives all its Masses at 42 Vail Road, Bethel (`our-lady-of-aparecida-bethel`).

## Name and address

The bulletin, the diocese's directory (directory:1360, "St. Peter Church", 104 Main Street) and GCatholic (22027, "St. Peter", 104 Main St.) agree: name and address verified. Coordinates are GCatholic's Plus Code 87H89HR2+Q8.
