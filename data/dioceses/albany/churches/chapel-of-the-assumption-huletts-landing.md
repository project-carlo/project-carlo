## Holds Mass

Yes, in summer: the 27 September 2026 bulletin (page 2) lists "6:00 pm *Chapel of the
Assumption (*summer schedule)" on Saturdays, and page 5 records a collection there for the
weekend of 20 September 2026, so Mass was still being said there in late September. It is a
seasonal mission chapel on Lake George; expect no Mass in winter.

## Name and address

Name: the bulletin calls it "Chapel of the Assumption"; the directory and GCatholic call it
"St. Mary of the Assumption". Same place (the directory groups it with Our Lady of Hope and
St. Ann's). The bulletin's name is used; name flag false because the names differ.

Address: the bulletin and the directory give 2026 Lands End Road, Huletts Landing 12841;
GCatholic gives "Lands End Rd." without a number: address flag true (two sources agree, the
third is consistent). No coordinates: GCatholic has no Plus Code for it and the directory has
none; left null for the geocode stage.
