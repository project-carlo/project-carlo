(page 1).

## Name and address

The name agrees everywhere (bulletin, directory "Holy Trinity Catholic Church", GCatholic,
OSM). The address does not: the bulletin says **22 E. Clinton St.**; GCatholic ("207 Gleebe
St.", a misspelling) and OpenStreetMap say **207 Glebe St.**; the diocese's directory says
"E. Clinton St. at Glebe St.", i.e. the corner. The church stands on that corner, so both are
probably the same building with a number on each street; the rectory is 205 Glebe St. The
row uses 207 Glebe St. (GCatholic + OSM, and the Plus Code falls on the OSM church), and the
address flag stays false until the parish's own preferred street address is settled (the
bulletin's 22 E. Clinton would be the one to adopt if it is the mailing address).
